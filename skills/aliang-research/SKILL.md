# Aliang Research：对标内容获取

## 目标与范围

从用户给出的作者主页或作品链接出发，找到账号的近期公开作品，将作品、评论需求和脚本结构整理为可追溯的研究结果；用户要求飞书多维表格时，将资料及实际文件放入表中。根据链接识别平台，默认研究最近 30 天（注明执行时间与时区）；用户指定平台、窗口或作品范围时从其要求。

首次处理前查相关项目的现有对标记录、工具和表格，避免重复创建或重复抓取；有 GitHub 项目上下文时先读取其适用规则和已有研究。区分历史快照与当次数据。已有可用材料优先复用，不要重复付费抓取。通过作品链接进入时核实其作者，主页短链接须先解析身份；不得凭链接猜账号。

## 采集与研究

1. 对用户要求的账号研究，如已安装 `pongfi-research`，读取其 SKILL.md 并动态发现可用社交数据工具及参数；否则使用可用的授权数据来源，无法访问时说明缺口。优先官方连接器或已授权的数据服务。先做 1–3 条样本检查，再按时间分页；记录采集时间、时间窗口、排序、分页和置顶作品的处理方式。服务收费时说明请求规模及费用信息，遇到认证、余额或限流问题按其故障边界停止或调整。凭据只通过已有安全机制传递，不写入文件、日志、表格或对话。
2. 每条作品保留平台作品 ID、原始链接、作者、原始标题或文案、发布时间、点赞、评论、分享、收藏、封面及可用视频。区分作品发布时间与采集时间，数据是快照；不存在或不可靠的字段留空并说明，接口返回的播放量 0 不能自动当作真实零播放。数值如 `1.9万` 转成 19000，`10+` 转成 10，并说明后者只是平台展示下界；无法确认的数值不要猜。
3. 获取作品列表后按真实发布时间过滤，保留分页是否完整、作品可见性及置顶的局限。用同账号、同一采集时点的可比指标和样本中位数观察相对表现，样本小、发布时间不同和缺少曝光时说明局限；不将点赞高直接归因于某种脚本。
4. 用户要求评论研究时，按作品抽取实际评论，记录每条作品的评论数、页数、排序和采集时间。提炼反复出现的具体问题、使用障碍、资料或成本需求；标明计数口径，首屏不是随机样本，不把单条意见称为高频或推广到全部观众。保留必要的匿名证据，不采集或展示无关个人信息。

## 视频、转写和脚本

- 用户要求下载时，对每条获取可访问的媒体地址，保存实际 MP4 并检查文件类型、大小及可解码性；失败保留原链接和失败原因。保存对应封面为图片文件；不要用即将过期的图片链接代替上传的封面图。下载只用于用户授权的研究和资料整理，遵循来源权限，不绕过登录、验证码或访问限制。
- 用户要求转写时，优先已有可用的本地语音识别或用户已授权的服务。先验证一条再批量；若需新依赖或模型，优先隔离临时环境，说明实际安装和外部传输情况。为每条产出带时间戳的完整机器转写稿，标注模型或来源、未听校及明显不确定词。保留原稿，不把画面 OCR 称为音频转写；不可用时如实说明并可提供标注限制的字幕 OCR 梗概。
- 按实际可获取的音频或字幕，逐条分析 **开场、句长、转折、结尾**。注明依据、覆盖范围及是否听校；句长若未统计，应写定性观察，不伪造平均字数或语速。先用已验证内容更新分析，未经检查的片段标记待核。

## 飞书多维表格

用户要求创建或更新飞书表格时，优先已连接的飞书专用工具；不足时使用授权的飞书客户端或浏览器。先按用户指定名称、位置查找已有表格；找到可编辑的目标则按原始链接或作品 ID 去重更新，避免创建重复表和覆盖用户其他字段。找不到时按用户要求创建，默认名称「对标视频库」。写入、上传与创建仅在用户授权范围内进行。

默认字段：

| 字段 | 类型与内容 |
| --- | --- |
| 视频标题、作者、视频描述 | 文本；描述保留来源原文，标题若由描述整理须标明 |
| 发布日期 | 日期时间，明确时区 |
| 点赞数、评论数、分享数、收藏数 | 数字；分享与转发字段含义按来源说明 |
| 封面图 | 图片附件，上传实际图片 |
| 原始链接 | 超链接；用于定位和去重 |
| 下载状态 | 单选：待下载、已下载、无法下载；以实际文件及上传结果为准 |
| 视频文件 | 附件：对应 MP4 |
| 脚本（script） | 文本：开场、句长、转折、结尾及证据限制 |
| 音频转写（未听校） | 附件或长文本：该作品带时间戳的机器转写稿 |

若表格已经有同义字段，优先复用并保持原字段及历史数据；需要改字段类型前先确认不会丢失已有内容。日期、数值、原链接和附件必须按作品 ID 逐行匹配。媒体和转写稿分别上传到对应记录，上传完成后逐项核实文件名、记录匹配、状态和四项脚本分析内容；不能只凭提交、进度动画或 AI 助手声称成功。无法完成时保留已完成结果并报告具体缺口，不能把本地已下载误称飞书已上传。

## 交付与记录

在表格或相邻报告中记录数据来源、采集时间、窗口、样本覆盖和限制；按需提供账号选题结构、评论需求与逐条脚本分析。原始响应、转写和下载文件分开保存，避免泄露凭据、带签名的临时链接及评论用户资料。最终给出表格链接、作品和附件完成数量、转写与听校范围，以及无法获取或未验证的事项。不主动发布、发送消息或提交 Git。

## 公开分享与隐私

分享 skill 仓库时只包含通用流程和虚构示例。真实账号、用户及第三方身份信息、作品链接或 ID、视频、封面、评论、转写、采集数据、表格链接、截图、运行日志、绝对路径、凭据及带签名的临时链接默认不纳入；如需分享真实素材，须逐项取得适当授权并经用户明确确认。脱敏只针对公开分享材料，不擅自删改用户自己的研究成果。公开前检查正文、示例、附件和 Git 历史。
